## Bending Plugin inspired by Avatar: The last Airbender and ProjectKorra
Personal take on a bending plugin.
The goal is to create a more dynamic bending situation in the world of Minecraft
with abilities feeling more alive and interacting in special ways with each other and much more.

## How to build plugin (Gradle)
1. Clone the repo `git clone https://github.com/Manu585/FourElements.git`
2. Open repo in IDE and wait for IDE to configure the Gradle project
3. Build with the `shadowJar` task created in the bukkit modules `build.gradle.kts`. <br> Either with command line `.\gradlew shadowJar` or with IDE GUI
